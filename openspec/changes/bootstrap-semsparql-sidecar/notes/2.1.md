## Exported-Surface Ownership Check ("Before adding anything new")

1. **Who owns this responsibility today?**
   - Neither SemEngine (`v0.1.0-alpha.2`) nor SemVocab (`v0.1.0`) owns a SPARQL parser or AST (`inventory.md:27-31`;
     ADR-107 places SPARQL execution in SemSparql).
   - Error classification is owned by `github.com/c360studio/semengine/pkg/errs` (`*errs.ClassifiedError`,
     `errs.ErrorInvalid`), which `sparql` reuses directly for `ErrSyntax` and `ErrUnsupportedFeature`.
2. **Is the premise true?**
   - Confirmed in `openspec/changes/bootstrap-semsparql-sidecar/inventory.md`.
3. **Who is it for?**
   - `Parse`, `Query`, `QueryForm`, `GroupPattern`, `PatternElement`, `BGPPattern`, `OptionalPattern`, `UnionPattern`,
     `SubGroupPattern`, `PathKind`, `TriplePattern`, `TermKind`, `Term`, `FilterExpr`, `TermExpr`, `UnaryOp`,
     `UnaryExpr`, `BinaryOp`, `BinaryExpr`, `BuiltinFunc`, `CallExpr`, `OrderDirection`, `OrderCondition`,
     `ErrSyntax`, `ErrUnsupportedFeature`: consumed by `sparql` planner/executor (`Task 2.2`), virtual type/subclass
     resolver (`Task 3.1`), `FoldProjections` (`Task 3.2`), `CONSTRUCT`/`DESCRIBE` evaluator (`Task 3.3`), and `server`
     `/sparql` + `/export` HTTP handlers (`Tasks 2.3, 3.3`); specified in `design.md` ("Responsibilities and consumer
     surfaces") and `specs/sparql-protocol/spec.md`.
4. **Am I asking a caller to predict something the server could observe?**
   - No; `Parse` resolves `BASE` and `PREFIX` declarations onto every IRI in the AST, normalizes `a` and the two
     supported property paths, and classifies syntax vs unsupported-feature errors automatically.
