## Key Implementation Choices

1. **Module & Dependency Pins (`go.mod`, `go.sum`)**:
   - Initialized `module github.com/c360studio/semsparql` at `go 1.26.9` (matching
     `semengine@v0.1.0-alpha.2` and `semvocab@v0.1.0`).

     as direct requirements with zero `replace`, `exclude`, or pseudo-version directives.

     directives in `go.mod` so `task lint` and `task vuln` run deterministically without global tool
     installation drift.

     `scripts/cleanup-roots-check.sh`, `scripts/tree-state.sh`, and `scripts/cover-check.sh` (adapted from
     `semvocab@v0.1.0` and `semengine@67d0ee9`).
   - Updated `scripts/verify.sh` to run `task spec:check docs:check fmt:check tidy:check cleanup-roots:check`
     followed by `build vet lint vuln test:unit test:integration cover:check test:repeat`.
   - Updated `.github/workflows/ci.yml` with `actions/setup-go@b7ad1dad31e06c5925ef5d2fc7ad053ef454303e`
     (`go-version-file: go.mod`) and `.github/dependabot.yml` with the `gomod` ecosystem.

   - `agentsetup_test.go`: `TestAgentSetupParity` and `TestAgentSetupParitySensitivity` enforce task parity
